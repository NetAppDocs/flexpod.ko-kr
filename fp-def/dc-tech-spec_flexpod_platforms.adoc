= FlexPod 플랫폼
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod 플랫폼에는 2가지 플랫폼이 있습니다.

* *FlexPod Datacenter.* 이 플랫폼은 엔터프라이즈 워크로드 및 애플리케이션, 가상화, AI/ML, 데이터베이스, SAP HANA, 가상 데스크톱 인프라(VDI), 퍼블릭, 프라이빗 및 하이브리드 클라우드 워크로드 등에 적합한 확장성이 뛰어난 데이터 센터 인프라입니다.
* *FlexPod Express.* 이 플랫폼은 원격 사무실 및 에지 사용 사례를 대상으로 하는 소형 컨버지드 인프라입니다. FlexPod Express는 https://docs.netapp.com/us-en/flexpod/fp-def/fp-express-tech-spec_overview.html["FlexPod 익스프레스 기술 사양"^]에 문서화된 자체 사양을 가지고 있습니다.


이 문서에서는 FlexPod 데이터 센터 플랫폼의 기술 사양을 제공합니다.
