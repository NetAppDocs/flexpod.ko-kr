== FC 및 IP 기반 SAN을 지원하는 Cisco UCS X-Series 모듈형 시스템 및 C-Series 랙 서버

다음 그림은 IP 기반 iSCSI 구성을 위한 X-Series 모듈식 시스템 및 C-Series 랙 서버를 갖춘 FlexPod Datacenter의 예를 보여줍니다. 이 토폴로지는 NFS 및 NVMe-TCP도 지원합니다.

image:dc-tech-spec_image15.png["FlexPod IP 기반 iSCSI 연결을 위한 데이터센터"]

다음 그림은 MDS 스위치를 사용하는 FC 기반 SAN 구성을 위해 X 시리즈 모듈형 시스템과 C 시리즈 랙 서버를 사용하는 FlexPod 데이터센터의 예시를 보여줍니다. 위의 토폴로지는 NFS 및 FC-NVMe도 지원합니다.

image:dc-tech-spec_image16.png["FlexPod FC 기반 SAN 연결을 위한 데이터센터"]

위 토폴로지에 대한 연결 요구 사항은 다음과 같습니다.

* AFF 클러스터 연결: 2노드 AFF 클러스터의 경우, 클러스터 스위치를 사용하지 않고 컨트롤러를 케이블로 직접 연결할 수 있습니다.
* 스토리지 이더넷 연결: NetApp 스토리지 컨트롤러는 Cisco Nexus 스위치에 직접 연결해야 합니다.
* Cisco UCS X9508 섀시는 Cisco UCSX-I-9108-100G IFM을 사용하여 패브릭 인터커넥트에 연결됩니다. Cisco UCSX-I-9108-25G IFM은 섀시를 패브릭 인터커넥트에 연결하는 데 사용되는 4x25G 브레이크아웃 케이블과 함께 사용할 수도 있습니다.
* Cisco UCS X-Series 모듈형 컴퓨팅 노드에는 Cisco VIC가 포함되어 있으며 두 IFM 중 하나와 함께 사용할 수 있습니다.
* Cisco UCS C 시리즈 랙 서버에는 Cisco VIC가 포함되어 있으며 패브릭 인터커넥트에 연결됩니다.
* 가상 포트 채널(vPC)은 Cisco Nexus 스위치를 NetApp 스토리지 컨트롤러에 연결하고 Cisco UCS 패브릭 인터커넥트를 Cisco Nexus 스위치에 연결하는 데 필요합니다.
* FC 연결 요구 사항:
+
** NetApp 스토리지 컨트롤러는 SAN 연결을 위해 32Gbps FC 연결을 사용하여 Cisco MDS 스위치에 연결됩니다.
** Cisco UCS 패브릭 인터커넥트는 SAN 연결을 위해 단일 포트 채널로 구성된 32-Gbps FC 연결을 사용하여 Cisco MDS 스위치에 연결됩니다.




워크로드 지연 시간 및 처리량 요구 사항에 따라 서로 다른 프로토콜을 적용하기 위해 IP 기반 SAN만 구현하거나, FC 기반 SAN만 구현하거나, 또는 둘 다 구현하도록 선택할 수 있습니다. NVMe over Fabric 프로토콜은 더욱 효율적인 장치 연결, 명령 세트 및 CPU 사용률 감소 덕분에 지연 시간을 줄이고 초당 입출력 작업 수(IOPs)를 향상시킵니다.


NOTE: 위의 예시 토폴로지는 NetApp AFF를 사용하는 X-Series 모듈형 및 C-Series 랙 서버 솔루션 구성을 나타냅니다. 하지만 동일한 토폴로지를 NetApp ASA 및 FAS에도 사용할 수 있습니다.

이 구성에 대한 자세한 내용은 link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod Datacenter with Cisco UCS M7 IMM, VMware vSphere 8.0 및 NetApp ONTAP 9.12 설계 가이드"^]을 참조하십시오.



[[cisco-ucs-x-series-direct-with-direct-attached-fc-and-ip-based-san]]
== 직접 연결 FC 및 IP 기반 SAN을 갖춘 Cisco UCS X-Series Direct

다음 그림은 FlexPod 데이터센터 IP 기반 및 FC 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 샘플 토폴로지를 보여줍니다.

image:dc-tech-spec_image14.png["IP 기반 및 FC 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 토폴로지"]

이 토폴로지에 필요한 연결 요구 사항은 다음과 같습니다.

* ASA 클러스터 연결: 2노드 ASA 클러스터의 경우, 클러스터 스위치를 사용하지 않고 컨트롤러를 케이블로 직접 연결할 수 있습니다.
* 스토리지 이더넷 연결: NetApp 스토리지 컨트롤러는 내장된 패브릭 인터커넥트에 직접 연결할 수 있습니다. ASA의 두 스토리지 컨트롤러는 FI A와 FI B에서 제공하는 두 개의 독립적인 IP SAN 패브릭에 연결됩니다.
* FI 네트워크 업링크 연결: IP 기반 SAN 연결의 경우, 업링크 Nexus 스위치는 SAN 데이터 경로에 관여하지 않습니다. SAN I/O는 FI A 또는 FI B에 대한 연결을 사용하여 UCS 컴퓨트 노드에서 ASA 스토리지로 직접 전송됩니다. 따라서 VLAN 및 vPC를 지원하는 기존 랙 상단 스위치를 활용하여 FlexPod SAN 솔루션 환경에 외부 네트워크 액세스를 제공할 수 있습니다.
* FC 기반 SAN 연결을 위해서는 UCS FI(FC) 포트를 브레이크아웃 포트로 구성해야 합니다.
* FC 기반 SAN 솔루션에 Cisco UCS를 사용할 경우 FC 스위칭 모드로 구성해야 합니다.


Cisco UCS X-Series Direct는 일반 X-Series와 유사하게 스위치 연결 스토리지를 활용할 수 있지만, 외부 패브릭 인터커넥트 대신 내장 패브릭 인터커넥트를 사용합니다.

이 구성에 대한 자세한 내용은 https://www.netapp.com/pdf.html?item=/media/135828-flexpod-san-ucs-xdirect-asa-nva-deploy-guide.pdf["FlexPod Cisco UCS X-Series Direct 및 NetApp ASA를 사용한 SAN 솔루션"^]을 참조하십시오.

[NOTE]
====
위의 샘플 토폴로지는 NetApp ASA를 사용하는 직접 연결 스토리지 솔루션을 나타냅니다. 하지만 동일한 토폴로지를 NetApp AFF 및 FAS에도 사용할 수 있습니다.

IP 기반 직접 연결 NAS 스토리지 구성에 NetApp AFF 또는 FAS 스토리지를 사용하는 경우, 업링크 Nexus 스위치를 특정 장애 시나리오를 지원하도록 올바르게 구성해야 합니다. 자세한 구성 정보는 아래 링크를 참조하십시오.
