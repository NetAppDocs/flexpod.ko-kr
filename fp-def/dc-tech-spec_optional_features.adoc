NetApp은 FlexPod 데이터 센터 아키텍처를 한층 더 향상하기 위해 몇 가지 선택적 구성요소를 지원합니다. 선택적 구성 요소는 다음 하위 섹션에 설명되어 있습니다.


NOTE: SAN 부팅은 선택 사항이지만 하드웨어 업그레이드 또는 교체 시 서버 프로필을 이동할 수 있으므로 강력히 권장합니다.



[[iscsi-boot-option]]
== iSCSI 부트 옵션

iSCSI 부팅 옵션의 최소 요구 사항은 다음과 같습니다.

* NetApp 스토리지 컨트롤러에서 활성화된 iSCSI 라이센스/기능
* NetApp 스토리지 컨트롤러 HA 쌍의 각 노드에 있는 2포트 10Gbps 이더넷 어댑터
* iSCSI 부팅이 가능한 Cisco UCS 서버의 어댑터


다음 그림은 IP 기반 iSCSI 구성을 위한 X-Series 모듈식 시스템 및 C-Series 랙 서버를 포함한 FlexPod Datacenter의 예를 보여줍니다.

image:dc-tech-spec_image15.png["FlexPod IP 기반 iSCSI 연결을 위한 데이터센터"]

이 구성에 대한 자세한 내용은 link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod Datacenter with Cisco UCS M7 IMM, VMware vSphere 8.0 및 NetApp ONTAP 9.12 설계 가이드"^]을 참조하십시오.



[[fc-boot-with-cisco-mds]]
== Cisco MDS를 사용한 FC 부팅

전용 SAN 네트워크를 사용하여 확장성을 높이기 위해 FlexPod는 Cisco MDS 스위치를 통한 FC를 지원합니다. Cisco MDS를 통한 FC SAN 부팅 옵션에는 다음과 같은 라이선스 및 하드웨어 요구 사항이 있습니다.

* NetApp 스토리지 컨트롤러당 최소 2개의 FC 포트, 각 SAN 패브릭당 1개의 포트
* 각 NetApp 스토리지 컨트롤러의 FC 라이센스.
* FC 부팅이 가능한 Cisco UCS 서버의 어댑터.


다음 그림은 MDS 스위치를 사용하는 FC 기반 SAN 구성을 위해 X-Series 모듈형 시스템과 C-Series 랙 서버를 사용하는 FlexPod 데이터센터의 예를 보여줍니다.

image:dc-tech-spec_image16.png["FlexPod FC 기반 SAN 연결을 위한 데이터센터"]

이 구성에 대한 자세한 내용은 link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod Datacenter with Cisco UCS M7 IMM, VMware vSphere 8.0 및 NetApp ONTAP 9.12 설계 가이드"^]을 참조하십시오.



[[fc-san-boot-with-cisco-nexus]]
== Cisco Nexus로 FC SAN 부팅

Cisco Nexus 93180YC-FX, 93360YC-FX2 또는 9336C-FX2-E 스위치는 LAN과 SAN 모두에 대한 스위칭 패브릭을 제공하는 데 사용할 수 있습니다.

다음 그림은 Cisco Nexus SAN 스위칭을 사용하는 FC 기반 SAN 구성을 위한 X 시리즈 모듈형 시스템과 C 시리즈 랙 서버를 갖춘 FlexPod 데이터센터의 예를 보여줍니다.


NOTE: FC SAN 연결을 위해 Cisco Nexus 스위치를 사용하려면 Cisco Nexus 스위치에 스토리지 추가 라이선스가 필요합니다.

image:dc-tech-spec_image17.png["FlexPod Cisco Nexus를 사용한 FC 기반 SAN 연결을 위한 FlexPod 데이터센터"]

이 구성에 대한 자세한 내용은 link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod Datacenter with Cisco UCS M7 IMM, VMware vSphere 8.0 및 NetApp ONTAP 9.12 설계 가이드"^]을 참조하십시오.



[[end-to-end-fc-nvme]]
== 엔드 투 엔드 FC-NVMe

엔드투엔드 FC-NVMe는 고객의 기존 SAN 인프라를 실시간 애플리케이션에 맞게 원활하게 확장하는 동시에 향상된 IOPS와 처리량을 제공하고 지연 시간을 줄입니다. 기존 32G FC SAN 전송을 사용하여 NVMe 및 SCSI 워크로드를 동시에 전송할 수 있습니다.

이 구성에 대한 자세한 내용은 link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod Datacenter with Cisco UCS M7 IMM, VMware vSphere 8.0 및 NetApp ONTAP 9.12 설계 가이드"^]을 참조하십시오.



[[cisco-ucs-x-series-direct-and-direct-attached-aff-asa-fas-for-fc-and-ip-based-san]]
== FC 및 IP 기반 SAN을 위한 Cisco UCS X-Series Direct 및 직접 연결 AFF/ASA/FAS

NetApp 스토리지 컨트롤러는 상위 SAN 스위치 없이 Cisco UCS 패브릭 인터커넥트에 직접 연결할 수 있습니다. FlexPod은 UCS X-Series Direct에서 FC 및 iSCSI 부팅을 모두 지원합니다.

라이센스 및 하드웨어 요구 사항은 다음과 같습니다.

* NetApp 스토리지 컨트롤러에 프로토콜 라이센스가 필요합니다.
* 서버에는 Cisco UCS 어댑터(이니시에이터)가 필요합니다. 지원되는 Cisco UCS 어댑터 목록은 NetApp https://imt.netapp.com["IMT"^]을 참조하십시오.
* NetApp 스토리지 컨트롤러의 타겟 어댑터가 필요합니다.


다음 그림은 IP 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 토폴로지를 보여줍니다.

image:dc-tech-spec_image13.png["IP 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 토폴로지"]

* 참고: *

* Cisco UCS는 이더넷 스위칭 모드에서 구성됩니다.
* 타겟의 iSCSI 포트와 패브릭 상호 연결은 iSCSI 데이터용 이더넷 스토리지 포트로 구성됩니다.


다음 그림은 IP 기반 및 FC 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 토폴로지를 보여줍니다.

image:dc-tech-spec_image14.png["IP 기반 및 FC 기반 SAN을 위한 UCS X-Series Direct 및 직접 연결 ASA 토폴로지"]

* 참고: *

* Cisco UCS는 FC 스위칭 모드에서 구성됩니다.
* 타겟에서 패브릭 인터커넥트까지의 FC 포트는 FC 스토리지 포트로 구성됩니다.


이 구성에 대한 자세한 내용은 https://www.netapp.com/pdf.html?item=/media/135828-flexpod-san-ucs-xdirect-asa-nva-deploy-guide.pdf["FlexPod Cisco UCS X-Series Direct 및 NetApp ASA를 사용한 SAN 솔루션"^]을 참조하십시오.

[[metrocluster]]
== MetroCluster

FlexPod MetroCluster IP with VXLAN 멀티사이트 패브릭 솔루션은 서로 상당한 거리를 두고 떨어져 있지만 연결 및 페어링된 두 개의 FlexPods로 구성되며, 사이트 장애 발생 시에도 비즈니스 연속성을 제공하는 고가용성, 유연성 및 신뢰성 높은 데이터 센터 솔루션을 제공합니다. 사이트 간 최대 지원 거리는 약 435마일(700km)입니다.

FlexPod MetroCluster IP 솔루션에서 Cisco VXLAN 멀티사이트 솔루션을 사용하면 지리적으로 분산된 여러 데이터 센터에 배포된 VXLAN 패브릭을 상호 연결하고 중앙에서 관리할 수 있습니다. NetApp MetroCluster IP는 두 개의 NetApp 스토리지 클러스터 간의 동기식 복제 솔루션을 제공하여 캠퍼스 또는 대도시 지역에서 스토리지 고가용성과 재해 복구를 지원합니다. 이 솔루션을 통해 분산 통합 인프라에 VMware vSphere 기반 프라이빗 클라우드를 설계하고, 여러 사이트가 단일 사이트처럼 작동하는 통합 솔루션을 제공하는 동시에 전체 사이트 장애를 포함한 다양한 단일 장애 지점 시나리오로부터 데이터 서비스를 보호할 수 있습니다.

다음 두 그림에서는 VXLAN 멀티 사이트 패브릭 구축을 지원하는 FlexPod MetroCluster IP 솔루션을 위한 VXLAN 멀티 사이트 패브릭 및 MetroCluster IP 스토리지 패브릭을 보여 줍니다.

* FlexPod MetroCluster IP 솔루션용 VXLAN 멀티 사이트 패브릭


image:dc-tech-spec_image11.png["FlexPod MetroCluster IP 솔루션용 VXLAN 멀티 사이트 패브릭"]

* FlexPod MetroCluster IP 솔루션용 MetroCluster IP 스토리지 패브릭


image:dc-tech-spec_image12.png["FlexPod MetroCluster IP 솔루션용 MetroCluster IP 스토리지 패브릭"]

이 구성에 대한 자세한 내용은 https://www.cisco.com/c/dam/en/us/products/collateral/servers-unified-computing/flexpod-metrocluster-ip-vxlan-multi-site-wp.pdf["FlexPod MetroCluster IP with VXLAN 멀티사이트 FrontendFabric"^]을 참조하십시오.



[[snapmirror-active-sync-solution-for-flexpod-metrocluster-ip-solution]]
=== SnapMirror 액티브 동기화 솔루션(FlexPod MetroCluster IP 솔루션용)

NetApp ONTAP 소프트웨어의 NetApp Snapshot 기술을 사용하면 스냅샷 기반 백업의 데이터를 통해 미션 크리티컬 SAN 데이터 서비스를 신속하게 복원할 수 있습니다.

* 서로 다른 두 사이트에 배포된 두 개의 ONTAP 클러스터는 피어링되어 동기식 데이터 복제 및 재해 복구를 위해 SnapMirror 액티브 싱크로 구성됩니다.
* 아래 그림과 같이 ONTAP 미디에이터는 제3 장애 도메인에 배포됩니다. 클러스터와 함께 ONTAP 미디에이터는 SnapMirror 액티브 동기화 솔루션의 쿼럼을 완성합니다.
* ONTAP 미디에이터는 피어링된 ONTAP 클러스터 및 노드로부터 상태 정보를 수신하고, 이들 간의 조정을 통해 상태를 파악합니다. 상태 데이터는 클러스터가 다양한 유형의 장애를 구분하고 자동 페일오버를 수행할지 여부를 결정하는 데 도움이 됩니다.


image:dc-tech-spec_image18.png["SnapMirror 액티브 동기화 솔루션 구성 요소(FlexPod MetroCluster IP 솔루션용)"]



[[symmetric-active-active-multi-path-support-for-flexpod-metrocluster-ip-solution]]
=== FlexPod MetroCluster IP 솔루션을 위한 대칭형 액티브-액티브 멀티패스 지원

호스트/클라이언트가 복제된 LUN을 사용할 수 있도록 하려면 원격 클러스터에 igroup을 생성하고, 복제된 LUN을 해당 igroup에 할당하고, 호스트/클라이언트가 원격 클러스터에서 사용 가능한 iSCSI 타겟 및 LUN을 추가 경로로 찾을 수 있도록 설정해야 합니다.

아래 그림에서 보는 것처럼, 엔터프라이즈 애플리케이션은 사이트 간 동기식 데이터 복제를 위해 구성된 두 개의 ONTAP ASA 클러스터에서 호스팅되는 iSCSI 기반 LUN을 사용하여 스토리지 클라이언트에 배포할 수 있습니다. 다이어그램에 표시된 일관성 그룹에는 SnapMirror 액티브 동기화를 통해 피어링된 클러스터로 데이터가 동기적으로 복제되는 세 개의 애플리케이션별 LUN이 포함됩니다.

image:dc-tech-spec_image19.png["SnapMirror 액티브 동기화 대칭형 액티브-액티브 SAN 멀티패싱"]

자세한 내용은 https://community.netapp.com/community/discussion/465452/level-up-flexpod-san-solution-storage-resiliency-with-snapmirror-active-sync["SnapMirror active sync를 통해 FlexPod SAN 솔루션 스토리지 복원력 레벨 업"^]을 참조하십시오.
